# Fonte.ia by Olli - Pesquisa De Dominios

Data: 2026-06-10

Metodo usado:

- RDAP via `rdap.org` para dominios genericos.
- RDAP via `rdap.registro.br` para `.br`.
- DNS local via `Resolve-DnsName`.

Observacao: disponibilidade final deve ser confirmada no registrador no momento da compra. RDAP/DNS e uma triagem tecnica, nao uma reserva.

## Recomendacao

Comprar primeiro:

1. `fonte.ia`
2. `fonteia.app`
3. `appfonteia.com.br`
4. `fonteia.dev`
5. `fonteia.io`

Uso sugerido:

- Site principal: `fonte.ia`
- Aplicacao: `app.fonte.ia`
- API/docs: `docs.fonte.ia` ou `api.fonte.ia`
- Fallback Brasil: `appfonteia.com.br`
- Dev/API: `fonteia.dev`

Se `fonte.ia` nao puder ser comprado, usar:

- principal: `fonteia.app`
- Brasil: `appfonteia.com.br`
- API/docs: `fonteia.dev`
