# Design (referência)

Protótipo do design novo do Fonte.ia — HTML, JSX e CSS de referência, mais os screenshots das telas. Guia visual para repaginar o app em `apps/web`.

- **Origem:** pasta antiga `CLAUDE DESIGN` (renomeada para tirar o espaço do nome).
- **Uso:** referência visual apenas. **Não** faz parte do build nem é importado pelo código de produção.
- **Principais arquivos:**
  - `styles.css` — tokens de cor/tipografia (azul + teal, Figtree, dark/light).
  - `ui.jsx` — componentes base (Score Ring, sparkline, gráficos, contadores).
  - `screens-*.jsx` — telas (painel, lotes, detalhe, conta, etc.).
  - `sales-1.jsx` / `*.html` — página de vendas e telas estáticas.
  - `screenshots/` — telas renderizadas para conferência.
