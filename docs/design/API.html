Exemplo de integração

Uma chamada. Toda a inteligência.

Faça um GET para /lotes/:id e receba o lote completo — score, fontes, custo total e rastreabilidade — num único objeto JSON.

Requisição
curl
GET 
# Buscar análise de um lote
curl -X GET https://api.fonte.ia/v1/lotes/RFB-0042-87 \
  -H "Authorization: Bearer fia_live_8a2f…3f9a" \
  -H "Content-Type: application/json"

# Listar lotes com filtros
curl -X GET "https://api.fonte.ia/v1/lotes?orgao=rfb&risco=baixo&sort=score" \
  -H "Authorization: Bearer fia_live_8a2f…3f9a"
