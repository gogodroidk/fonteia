# Pesquisa e dados (referência)

Dados públicos coletados e notas de pesquisa que servem de base de domínio e de seed para o modo demonstração.

- **Origem:** pasta antiga `chat pesquisas` (renomeada para tirar o espaço do nome).
- **Uso:** referência de domínio e fonte de dados reais. **Não** faz parte do build.
- **Conteúdo:**
  - `analise_completa_editais_rfb.xlsx` — 20 editais da Receita Federal (cronogramas, contatos, regras).
  - `analise_completa_extratos_leilao_rfb.xlsx` — 3.317 arrematações reais.
  - `leiloes_rfb_dashboard_enriquecido_cnpja.xlsx` — 490 empresas (CNPJ) enriquecidas.
  - `leiloes_rfb_planilha_top_dashboard.xlsx` — top leads priorizados.
  - `planilha_apis_publicas_governo_brasil.xlsx` — 126 APIs públicas mapeadas.
  - `CNPJá - ...xlsx` — consulta CNPJ em massa.
  - `*.md` — notas de pesquisa (pipeline de leilões, extração de documentos).
